# PDPTW 混合优化：ALNS + CP-SAT

## 📌 项目简介

本项目针对 **PDPTW（Pickup and Delivery Problem with Time Windows，带时间窗的取送货问题）**，设计实现了一套 **ALNS（自适应大邻域搜索）+ CP-SAT（精确求解器）** 的混合求解框架。

核心思想：用 ALNS 做**全局探索**（破坏 + 修复 + 模拟退火接受准则），用 CP-SAT 做**局部精修**（单路径 TSP 重排序），形成"启发式 + 精确"的混合架构。

## 🎯 问题背景

PDPTW 是经典的 NP-Hard 组合优化问题，是物流调度、外卖派单、网约车等场景的核心数学模型。它要求：

- **每个订单有取货点和送货点**，且取货必须在送货之前
- **每个节点有服务时间窗** `[tw_start, tw_end]`
- **车辆有容量上限** `CAPACITY`
- **每条路径有时长上限** `MAX_ROUTE_DURATION`
- **每辆车最多服务 N 个订单** `MAX_ORDERS_PER_ROUTE`

**优化目标**：最小化 `总行驶距离 + 车辆数 × 固定成本`

## 🔬 算法架构

### ALNS 框架

```txt
初始解 (贪心插入)
    ↓
┌─────────────────────────────────────────┐
│  主循环 (迭代至时间耗尽)：               │
│    1. 按权重轮盘赌选择破坏算子           │
│    2. 按权重轮盘赌选择修复算子           │
│    3. 破坏：移除若干订单                 │
│    4. 修复：重新插入这些订单             │
│    5. 模拟退火接受准则：接受 / 拒绝      │
│    6. 更新算子得分、使用次数             │
│    7. 每 SEGMENT_SIZE 轮更新权重         │
│    8. 每 SOLVER_CALL_INTERVAL 轮调用 CP-SAT│
└─────────────────────────────────────────┘
    ↓
返回最优解
```

### 破坏算子（4 种）

| 算子 | 策略 |
| ---- | ---- |
| destroy_random | 随机移除 K 个订单 |
| destroy_shaw | 移除与种子订单最相似的 K 个订单 |
| destroy_worst | 移除"移除收益最大"的 K 个订单 |
| destroy_route | 移除整条路径上的所有订单 |

### 修复算子（3 种）

算子 | 策略
| - | - |
repair_greedy	| 按送货截止时间排序，逐个贪心插入
repair_regret	| 每次插"后悔值最大"的订单
repair_noise	| 在贪心基础上加相对噪声

### 自适应权重机制

- 每个算子维护一个权重，权重 = 历史表现得分
- 表现好的算子被更频繁选中（轮盘赌）
- 每 100 轮根据得分更新权重：

```txt
新权重 = (1 - α) × 旧权重 + α × 平均得分
```
- 得分规则：找到新最优 +10、改进 +5、接受差解 +2

### CP-SAT 精修

- 周期性调用：按时间间隔（非迭代次数）触发
- 作用范围：单条路径内重排序节点（本质是 TSP）
- 建模方式：
变量：弧变量 x[i][j] + 时间变量 start[i]
约束：AddCircuit 强制单回路 + 时间窗 + 时间推进 + 取送顺序
目标：最小化总距离
- 安全机制：不可行解立即丢弃，不污染主解

## 🔬 技术要点

### 1. 自适应权重机制

- 算子权重根据历史表现动态调整
- SCORE_NEW_BEST=10、SCORE_IMPROVE=5、SCORE_ACCEPT=2
- 每 SEGMENT_SIZE=100 轮更新一次
- 通过REACTION_FACTOR=0.2平滑更新，避免剧烈波动

### 2. 模拟退火接受准则

- 更好的解：无条件接受
- 更差的解：以概率 exp(-Δ/T) 接受
- 温度每 100 轮降温一次：T = T × cooling_rate
- 温度低于 min_temp 时，不再接受差解

### 3. CP-SAT 精修

- 50轮迭代一次
- 单路径时间限制 1 秒，防止单条路径过久
- 不可行解拦截：精修后立即验证，不可行则放弃

## 🎯 项目亮点 

- 完整的 ALNS 框架：4 种破坏 + 3 种修复算子，覆盖"广度探索"到"精细开发"
- 自适应权重机制：算子根据表现自动调整使用频率
- CP-SAT 混合精修：从"启发式"到"启发式 + 精确"，质量更高
- 鲁棒性保障：不可行解拦截、时间预算保护、量纲统一
- 可复现性：固定随机种子，结果可复现

## 🔍 改进方向

- CP-SAT 双路径合并：尝试合并低负载路径，进一步减少车辆数（当前未实现）
- 自适应时间预算：根据问题难度动态调整精修比例
- 算子扩展：加入基于聚类的破坏算子（如 destroy_cluster）
- 并行化：多进程并行求解不同初值，取最优解
